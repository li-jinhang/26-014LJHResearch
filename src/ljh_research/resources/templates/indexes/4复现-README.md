# 4复现

用于保存论文实验复现的卡片：从论文中查找官方代码（或无官方代码时按论文实现），在本仓库框架下重构得到可运行代码，并通过「指标对齐循环」把主指标与论文公布值对齐。对齐循环退出条件：全部对齐指标达标（默认相对偏差 ≤ 2%，可用容差调整），或完成 10 轮。 

## 状态说明

- `planned`：尚未完成复现设计。
- `setup`：正在准备代码、数据或运行环境。
- `running`：正在运行指标对齐循环。
- `reproduced`：全部对齐指标在容差内，复现成功。
- `partial`：完成上限或部分指标对齐，保留偏差与结论。
- `failed`：复现失败，保留失败证据。
- `blocked`：被外部依赖或缺失资源阻塞。
