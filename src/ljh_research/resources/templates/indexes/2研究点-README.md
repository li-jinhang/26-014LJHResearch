# 2研究点

用于保存有证据支撑、可持续优化的潜在研究方向。研究方向生成结果默认只作为对话草案；用户确认后再创建卡片。

## 状态说明

- `draft`：已有初步假设，尚未系统验证。
- `active`：正在补充证据、实现或实验。
- `validated`：关键假设已有可复核支持；这不等于自动进入主框架。
- `paused`：受资源、依赖或优先级限制暂缓。
- `rejected`：关键假设已被证伪，保留卡片供复盘。

框架采纳另由 `framework_adoption` 记录：`not_assessed`、`pending_decision`、`adopted`、`deferred`、`superseded`。只有 `validated` 卡片才能进入采纳决策。
