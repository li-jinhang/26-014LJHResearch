# 3实验

用于保存已确认的具体实验方案、评估协议、指标定义、实现产物与结论。2研究点存放“方向假设”（`[[2研究点/README|2研究点]]`），3实验存放“如何验证这些方向”的实验设计与执行记录；两者通过 ID（RP-NNNN / EXP-NNNN）互相引用。

## 状态说明

- `planned`：方案已确认，尚未开始执行或尚缺前置资源。
- `running`：正在实现或运行实验。
- `completed`：实验已执行并有当前判断。
- `failed`：运行失败，保留失败证据。
- `invalid`：协议或变量控制无效，不能作为科学结论。
