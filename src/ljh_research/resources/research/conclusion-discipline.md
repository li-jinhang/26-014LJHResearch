# 科学结论与继续投入的判断

停止投入与否定科学假设是两个决定。可以因为已有答案、低信息收益或资源边界结束任务，而无需宣称整个方向不可行。预算与尝试次数是资源事实，不是反证。

| 证据类型 | 应记录的判断 | 下一步标准 |
| --- | --- | --- |
| invalid：实现错误、控制失败、数据泄漏、协议不一致或输出不完整 | 保存失效原因和可用片段，不将结果用于支持/否定机制 | 只有修复能提供必要信息且在范围/预算内时才修复；否则停止并说明未能验证 |
| valid negative：可信但未支持预期 | 按数据、实现、优化、测量或机制层区分解释，写明适用条件与竞争解释 | 继续必须说明下一个动作能区分什么；不存在有价值动作时停止，不要求穷尽固定数量优化轴 |
| mixed/partial：不同指标、群体或设置方向不一致 | 保留各项真实结果、预先选择规则和不确定性，避免事后挑选有利指标 | 仅当子群差异或权衡关系值得解释时开展后续分析 |
| preliminary positive：观察到预期效果 | 立即保存结果、方法、局限和初步证据，区分探索与验证 | 根据主张所需证据选择对照、重现、稳健性；不把任意 seed 重复作为落库前置 |

主张“在这些条件下未支持”只需相应受控证据；主张“某机制被该试验反驳”须说明具体预测与证伪边界；主张“整个方向不可行”需要覆盖其适用范围的论证，有限实验通常达不到。实现完成不是科学验证；单次指标上升不是可推广的提升。

研究结果保留数据版本、协议、配置、代码、指标、选择方法和来源。指标/seed 选择遵循项目约束；额外种子用于稳健性而非选最优。未预先声明的分析标记探索性。需要锁定 Test 时，先固定选择和评估口径。负面与无效证据均保存，但两者的解释不同。

manual 在本次授权交付物完成或触发终止条件后封存，建议下一步由用户决定。auto 根据已登记判据自动 continue/pivot/stop；可信负面可以完成研究任务。RP 状态更新须有来源和判断依据，并在授权范围内；框架采纳仍是独立人工决定。结论范围应与证据范围一致。
