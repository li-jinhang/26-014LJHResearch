# 全局只保留 setup，科研版本部署到单一项目

用户要求科研指引只在被配置的项目中生效。全局保留 ljh-research-setup；auto/manual 模板放入独立核心安装资源，退出全局 skill 发现。setup 将所选版本部署到 `<project>/.agents/skills/ljh-research/`，同一项目只有一个固定入口，不同时暴露未选择版本。此前 0009 关于全局两个研究入口和兼容路由的位置决定由本决策替代，科学行为契约保留。

版本选择仍是项目约束 update_mode 的唯一事实来源，已有任务保留快照。选择/切换同步部署内容，备份被替换的管理文件，保留额外文件，遇到手工改动或非托管旧 skill 拒绝覆盖。启动器绑定安装所在项目，参数和 stdin 不能将它转向其他项目。外部控制模块继续使用公开协议，不读模板目录。

科研记忆目录统一为 `ljh research docs`，与 `.agents/skills/ljh-research` 分开。旧 `ljh research` / `.ljh-research` 由 setup 显式迁移，创建时拒绝另起平行目录；迁移要求受支持的所有权标记、无活动/未知执行、目标不存在，并备份改动的引用/账本。失败回滚目录和元数据，历史事件保留原始路径。迁移锁阻止新的账本操作；中断留下的锁须核实原进程后由 setup 人工恢复，不承诺跨文件系统的崩溃原子性。

原全局 Git 仓库和工作文件已完整归档到应用的 archives/，不以删除用户历史作为退出全局发现的代价。真实科研项目不参与工具回归；只在明确目标或隔离样例中部署与迁移。
