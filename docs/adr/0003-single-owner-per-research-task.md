# 每个科研任务同一时间只有一个有效研究驱动方

coding agent 和外部控制模块均可驱动科研任务，但同一个任务在同一时间只能有一个驱动方负责推进。其他入口可以查看任务或提交请求；通过明确接管再转移任务控制权，以避免重复启动实验、冲突状态和重复消耗预算。

此约束针对任务推进，不限制任务内调用不同推理提供方。驱动方退出或失联时停止安排新动作，保留已经启动的实验运行；接管者核实执行插件提供的运行身份、状态及结果后再决定下一步，不能因为聊天或界面结束而直接判定训练失败、重启或重复计费。

任务控制状态与实验运行状态分别记录。首版同一科研工作区同时推进一个科研任务，其余任务排队；单个任务内部可以依据授权和资源条件安排多个实验。这分别约束工作区级任务调度与任务内实验安排。

v0.1 通过事务记录和有时限的 lease 实现单一控制权；取消调度与停止实验分别处理，不确定运行支持人工核实关闭。接口见 `docs/contracts.md`。
