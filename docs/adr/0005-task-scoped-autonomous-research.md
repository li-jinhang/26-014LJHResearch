# 自动研究使用任务级授权

支持用户对科研任务明确指定研究目标、允许修改的目录、资源预算和停止条件。研究驱动方可在授权范围内连续实现、训练、分析和调整，无需对已授权的例行操作重复请求同意。coding agent 与外部控制模块遵循同一任务授权；授权不随更换推理提供方而扩大。

任务控制权与用户授权分别管理。自动模式本身不构成无限代码修改或资源使用许可；越出任务授权范围时需要用户决定。主框架采纳等独立决策闸门继续保留。

持久化保存任务配置、用户授权及剩余预算。更换会话或研究驱动方后，通过明确接管可在原授权范围内继续，恢复不会重置已消耗预算。任务采用启动时确认的配置版本；修改工作区默认配置不隐式改变运行中的实验条件。扩大范围或增加预算需要用户重新授权。

聊天中的用户明确确认与显示面板中的用户确认均可用于人工决策，由公共核心统一记录决策对象、具体内容及结果。研究驱动方只能提交请求，不能把自身输出的同意作为用户确认。

v0.1 使用事务式运行记录持久化上述契约，提供显式撤销和人工预算扩展。配置变更用于后续任务；已有任务保留快照。运行模式文档已同步，可信本地进程与操作系统沙箱的边界见公开协议。
