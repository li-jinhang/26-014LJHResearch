# 公共程序以独立可安装核心包提供

科研操作与校验、工作区和配置契约、状态管理及共享资源通过独立可安装的公共核心包提供。`ljh-research`、`ljh-research-setup` 和外部控制模块使用其公开接口，不依赖彼此 skill 的目录位置，不通过查找相邻目录或修改 `sys.path` 共享实现。

由 setup 准备核心包的运行条件。公共核心、参考控制模块、本地执行插件和面板在 `D:/_Projects/26-014LjhResearch` 的独立包中维护；两个 skill 保留在用户 skills 目录。该边界增加了打包和接口维护工作，但避免复制共享代码，并允许独立更换驱动方和显示面板。首版公开协议为 v1，提供独立 wheel 和原生引导流程；平台与安装验证范围单独记录。
