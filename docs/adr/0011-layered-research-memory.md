# 采用统一的分层记忆与按需读取接口

用户指出领域双根存储与大篇幅历史笔记无法支撑稳定读取范式，要求论文原件与提取内容直接位于 1论文，并将领域/机制知识作为自动提炼的引用视图；相同原则贯穿实验、研究点、复现和经验。先用已有资料的小规模副本验证，不修改真实科研目录。

原件/全文/完整记录构成证据详情；每个稳定对象有单项知识点；领域和方法专题聚合单项；0知识库跨类型联结来源。分类为多标签，不决定原件位置。知识点标注文献主张、既有研读笔记、项目记录、推断或未知，并保留适用条件与精确引用。

核心提供 memory.import/extract/search/read/rebuild/status。结构提取是保守摘录，agent 通过相同公开接口做语义回写；引用必须匹配实际行范围与 SHA256。语义回写增量合并，显式 supersedes 修订，旧版有历史快照。读取先按问题/用途搜索，再展开主题、对象、指定证据；预算按完整 JSON 结果的 Unicode 字符计量，省略整条知识而非截掉结论限定。索引与专题可重建，科学记录仍以 Markdown 为真源。

来源变化使摘要失效；失效专题只返回路由，不能照常输出旧正文。默认上下文从任意文件截取改为相关记忆、最近两条科学记录和证据定位，不自动加载整份任务历史。外部控制模块只依赖公共协议，manual/auto 共用同一记忆模块。

新论文导入和经验追加默认走新布局；已有主题双根行为仅在显式 legacy 兼容路径保留，以验证历史功能而不作为新工作流。真实目录迁移另行显式处理，样本复制与验证仅在应用项目 .local 内进行。结构检查不能证明语义质量；外部模型自动研读的质量不因协议夹具通过而被宣称已验证。
