# 将配置准备分离到独立的 ljh-research-setup skill

为配置准备建立独立的 `ljh-research-setup` skill，承载可复用的环境检测、配置准备和验证流程。范围包含工具运行环境、研究工作区初始化、项目路径、实验环境，以及 agent 或外部控制模块的接入配置。将现有 `ljh-research` 的工作区生命周期入口及其对应的准备流程迁移至 setup，避免两个 skill 各自保留初始化实现。

`ljh-research` 聚焦已配置工作区中的科研操作及证据管理，保留执行这些操作所需的只读预检；缺失初始化或必要配置时转交 setup。工作区路径解析、所有权校验、配置读取、卡片元数据解析等日常共享能力不因初始化入口迁移而归 setup 独占，迁移时应先明确公共程序边界。

显示面板通过稳定接口使用配置和能力检测结果，避免依赖安装流程与环境管理工具的实现细节。初始化只能创建空白结构，不生成研究事实；未知项目参数由用户提供和核验。公共程序采用 ADR-0004 的独立可安装核心包。setup 的环境安装与配置变更权限、具体数据约定尚待确定。v0.1 已创建独立 setup skill 并迁移运行代码；具体实测边界见 `docs/verification.md`。

setup 覆盖机器缺少 Python 的情况。coding agent 先按目标系统的原生引导流程准备合适的运行时，再准备隔离环境、核心包和功能依赖；引导阶段不能要求尚未安装的 Python。优先复用已经存在且符合要求的运行时。具体安装来源、支持平台、变更计划和用户级安装路径须在实现流程中明确。
